## 이 워크스트림이 지는 것

`prove.smt-product` 는 Bitwuzla 를 명시적 trusted-backend policy 로 신뢰합니다(envelope 에 `checked_proof=false`). AIG/SAT 경로는 그 신뢰를 줄이는 두 번째 방법입니다. miter 를 AIG 로 내리고 SAT solver 의 **UNSAT proof 를 독립 checker 로 검증**하면 `checked_proof=true` 인 첫 판정이 나옵니다.

## 순서

1. **조사부터.** SAT solver 와 proof 형식(DRAT/LRAT)과 checker 를 무엇으로 벤더링할지 후보 비교를 `docs/notes/` 에 남기고 ask 로 조율자 확인을 받습니다. 후보 예: kissat 또는 CaDiCaL(solver), drat-trim 또는 lrat-check(checker). 라이선스와 크기와 크로스플랫폼을 봅니다. **자체 SAT solver 를 만들지 않는 것은 SMT 와 같은 원칙입니다.**
2. loop-free scalar IR 의 **AIG 하강**(bit-blasting). 메모리는 첫 절단에서 제외하고 `UNKNOWN` 으로.
3. miter 를 CNF 로, solver 를 process 격리로(기존 Bitwuzla adapter 의 snapshot/deadline/출력 상한 패턴을 따름), **UNSAT proof 를 checker 에 통과시킨 뒤에만** `PROVED_*` 에 `checked_proof=true`.
4. SAT 배정은 기존 replay 경로(`ir_interp`)로 확인 후에만 `COUNTEREXAMPLE`.
5. **concrete differential refutation method.** 무작위/경계 입력으로 좌우를 `ir_interp` 로 돌려 반례를 찾는 싼 method. 반례는 정의상 replay 된 것이므로 바로 `COUNTEREXAMPLE` 자격이 있고, 못 찾으면 `UNKNOWN`(증거 아님)입니다. registry 에 등록해서 파이프라인에서 SMT 와 병렬로 쓸 수 있게 합니다.
