# W5. miter 의 메모리 절반

브랜치: `w5-miter-memory`
담는 GOAL: G5 의 확장(포인터 IR 에 대한 판정), G9 의 후반부
진행 기록: `docs/workstreams/W5-progress.md`

**시작하기 전에 `docs/workstreams/README.md` 를 읽습니다.**

## 이 워크스트림이 지는 것

W2 가 만든 `prove.smt-product` 는 loop-free scalar IR 만 SMT 로 옮깁니다. W1 이 그 사이 IR 에 flat memory model 을 넣었고(포인터, LOAD/STORE, object base/size 파라미터, IR 로 내려간 접근 정의성 술어) 로어링이 포인터와 struct 함수를 내기 시작했습니다. **그 IR 이 miter 에 들어가면 지금은 UNKNOWN 으로 떨어집니다.** 이 워크스트림이 miter 와 replay 를 메모리까지 넓혀서 포인터 함수가 실제 판정을 받게 합니다.

계약은 이미 문서화되어 있습니다. **`docs/workstreams/W1-progress.md` 의 메모리 모델 절이 정본입니다.** object 배치 결정([C parameters in source order][__memory once][base/size per pointer parameter]), ASSUME 과 guard 의 모양, 접근 정의성 술어가 IR 안 일반 산술이라는 것까지 전부 그 문서에 있습니다. 그것과 어긋나게 만들면 replay 가 판정을 무효화합니다.

`src/ir*.c`, `src/c_lower*.c` 는 W1 소유입니다. 읽기만 합니다. IR 에 필요한 것이 있으면 ask 로 조율자를 거칩니다.

## 순서

1. **SMT 인코딩.** 메모리를 배열 이론(select/store)으로, object base/size 를 좌우 공유 심볼 입력으로, disjointness 와 null 페이지 제약을 ASSUME 으로. 접근 정의성 술어는 IR 에 이미 산술로 있으므로 **다시 구현하지 않고 그대로 옮깁니다.**
2. **관찰 축.** 반환값에 더해 externally reachable final memory 비교가 필요합니다. 좌우가 같은 object 집합을 받으므로 최종 메모리 비교는 object 별 select 동치로 진술됩니다. 계약의 observation 비트를 정확히 따릅니다.
3. **counterexample decode 와 replay.** model 에서 object 내용과 base/size 를 복원해 `ir_interp` 의 메모리 모델로 replay 합니다. 인터프리터가 이미 그 입력 형태를 받습니다(W1 시험 참고).
4. **end-to-end.** 포인터 함수 쌍으로 `PROVED_*`(예: `*p += 1` 두 표현), `COUNTEREXAMPLE`(예: 다른 인덱스에 쓰기), `UNKNOWN` 세 판정의 통합 시험. struct 멤버 접근 쌍도 포함합니다.
5. 닫으면 val 코퍼스에서 **로어링된 본문 중 판정까지 간 비율**을 재서 worker_done 에 포함합니다.

## 넘지 않는 선

`AGENTS.MD` 전문에 더해 특히:

- raw `UNSAT` 은 여섯 조건이 결합된 trusted-backend policy 없이 `PROVED_*` 가 아닙니다 (기존 코드가 강제. 약화 금지)
- replay 가 확인하지 못한 model 은 `COUNTEREXAMPLE` 이 아니라 `UNKNOWN` + 로그입니다
- 메모리 의미론을 좁게 해석해 통과시키지 않습니다. 인코딩 못 하는 IR 은 `UNKNOWN` 입니다

## 하지 않는 것

- 로어링 확장(지역 object, calls, globals)은 W1 입니다
- 루프, bounded unrolling, CHC 는 아직입니다
- scheduler/plugin 기능 확장 금지
